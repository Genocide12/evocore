# EvoCore ARENA

**Гонки саморазвивающихся мутантов · Self-Evolving Code Races**

Программа, которая развивает собственный код и показывает это как азартные гонки:
мутанты выходят на трек, их скорость — это реальный бенчмарк их исходников (elem/s),
а чемпион заезда перезаписывает геном программы. Ставки на семейства считаются
по честной статистике побед.

## Что это

Внутри живёт «организм» — Python-файл `evolution/genome_core.py` с горячей функцией
`hot_path()`. Генетический алгоритм порождает популяцию мутантов (реальные варианты
исходного кода), каждый заезд измеряет их фактическую скорость, и если чемпион
статистически быстрее текущего кода организма — программа **атомарно перезаписывает
собственный файл генома** и продолжает жизнь на новом коде.

Дашборд превращает этот процесс в гонки: каждое поколение — заезд, каждое семейство
стратегий — команда, каждая ставка и коэффициент — производные реальных замеров.
Никаких выдуманных чисел: то, что вы видите на треке, происходит в CPU в этот момент.

Типичный результат: организм ускоряется в **×4–6.5** относительно наивного базового
кода за первые десятки поколений (полином 8-й степени, 24 000 элементов, fitness = elem/s).

## Как проходит заезд

1. **Сборка популяции** — движок строит мутантов из чемпиона прошлых заездов
   (мутации, кроссовер) и свежих иммигрантов.
2. **Гейт корректности** — каждый мутант сверяется с эталоном (допуск `1e-9`).
   Ошибочный код не выходит на трек: на арене он помечается как отбракованный.
3. **Бенчмарк** — замер элементов/сек в одном временном окне, head-to-head против
   текущего кода организма (3 чередующихся раунда).
4. **Финиш и подиум** — места распределяются по реальной скорости; победитель
   получает корону.
5. **Установка генома** — если чемпион быстрее организма более чем на 1.5%,
   его код записывается в `genome_core.py`. Это золотое событие: баннер, частицы,
   новый уровень организма.

```
 ┌──────────────┐   мутанты (реальный Python-код)
 │  Движок GA   │──────────────┐
 │  (генетич.   │              ▼
 │  алгоритм)   │      ┌──────────────┐
 └──────────────┘      │ Корректность │  ошибка → отбраковка (DOA)
                       │    + скорость│
                       └──────┬───────┘
                              ▼
                 чемпион быстрее на >1.5%?
                              │ да
                              ▼
              АТОМНАЯ перезапись genome_core.py  ← организм живёт на новом коде
                              │
                              ▼
                        Следующий заезд
```

## Игровые механики

- **Гонки** — 5 семейств стратегий (`naive`, `pow_cache`, `horner`, `direct`,
  `unroll`) с узнаваемыми цветами и глифами; скорость на треке повторяет
  реальный разброс бенчмарков.
- **Тотализатор** — ставьте монеты на семейство-победителя. Коэффициенты не
  выдуманы: они выводятся из журнала реальных побед со сглаживанием Лапласа
  и маржой арены 10%. Сорвали банк — монеты ваши (localStorage).
- **Уровни организма** — от «Прокариота» до «Легенды арены»: каждое ускорение
  ×1.25 / ×1.75 / ×2.5 / ×3.25 / ×4.25 / ×5 поднимает лигу.
- **Режим иммиграции** — 8 заездов без улучшений, и популяцию вливают свежие
  мутанты (punctuated equilibrium) — эволюция снова идёт в разнос.
- **Спонсор биолаборатории** — полный банкрот? Вернут +100 монет и не будут
  вспоминать этот момент.

## Быстрый старт

**Требования:** Node.js ≥ 20, Python ≥ 3.9 (только stdlib — `pip install` не нужен).

```bash
git clone https://github.com/Genocide12/evocore.git
cd evocore
npm install
npm run dev
```

Откройте `http://localhost:3000`, сделайте ставку и нажмите **«Старт эволюции»**.

## Консольный режим

Движок полностью управляется и без дашборда:

```bash
python3 evolution/evolution_core.py --generations 50 --population 16   # запуск эволюции
python3 evolution/evolution_core.py --reset                            # сброс к базовому геному
python3 evolution/evolution_core.py --quiet                            # вывод без ANSI-цветов
```

## Дашборд

| Элемент | Описание |
| --- | --- |
| Трек эволюции | canvas-гонки мутантов, подиум, короны, золотой баннер установки генома |
| Тотализатор | ставки на семейства, живые коэффициенты, история ставок, спасение банкрота |
| Карточки | заезд/поколение, лучший мутант, сила организма (×NN + лига), метаболизм |
| Код организма | текущий исходник `genome_core.py` — то, что программа о себе переписала |
| Журнал арены | события движка: старты, установки, стагнации, финиш |
| Динамика силы | график best/организм/ускорение по поколениям, золотые точки — установки |

## Архитектура

```
evocore/
├── evolution/
│   ├── evolution_core.py   # движок: GA, операторы, гейты, бенчмарк, атомная запись, данные заездов
│   ├── genome_core.py      # геном — файл, который программа перезаписывает сама
│   └── state/              # состояние прогона (создаётся в рантайме)
├── src/
│   ├── app/                # Next.js: арена + API (/api/evolution/status, /control)
│   ├── components/arena/   # race-canvas (гонки), bet-panel (тотализатор)
│   ├── lib/arena.ts        # семейства, коэффициенты, уровни, банк игрока
│   └── lib/evolution.ts    # управление процессом движка (spawn / stop / reset)
├── docs/dashboard.png      # скриншот арены
├── Dockerfile              # Node 20 + Python 3 в одном образе
└── package.json
```

## Развёртывание

Приложение состоит из долгоживущего Node.js-сервера, фонового Python-процесса и
записываемого состояния, поэтому ему нужна постоянная среда выполнения.
В репозитории готов Dockerfile (Node 20 + Python 3).

**Docker**

```bash
docker build -t evocore .
docker run -d -p 3000:3000 --name evocore evocore
```

**Railway / Render / Fly.io** — импортируйте репозиторий из GitHub: платформа
обнаружит Dockerfile автоматически. Порт — `3000`.

**VPS** — те же команды Docker, либо классически:

```bash
npm install && npm run build && npm start
```
